# Stitch布局来源与2.0实现

- 项目：Naraka Celestial Trading Hub，`projects/12277695699765981075`。
- 用户选定页面：`projects/12277695699765981075/screens/4a7062a088a34089b47f9c56bbb4b741`。
- 画布标签：最终布局；原始页面标题：永劫无间 · 谪星阁（简约门户版）。
- 通过Stitch MCP只读取项目与设计，没有修改Stitch中的原稿。
- 首页插画沿用设计导出素材；商品图仍使用官方CDN的真实商品原图。

以原稿的浅色背景、金色点缀、横向导航、双栏主视觉、三个工具卡、四件商品和社群区域为布局依据，使用本地CSS实现，无Tailwind CDN或字体服务依赖。数字、商品、状态和链接接入现有真实数据。

设计稿的示例毫秒同步、固定连接成功、满属性评分、社区联系方式没有事实配置，实施时分别替换为实际观察时间/快照说明、采样状态、原始星格与社群筹备提示。洗练继续明确为样本演练，费用规则继续可调整。

已有私有站点复用原地址和访问范围；静态线上版本不随本机30分钟任务自动更新，页面继续显示该口径。
