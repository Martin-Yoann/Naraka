# 抽签低价和微信接入

已具备网站应用，待管理员将真实配置写入服务器。桌面扫码登录与公众号通知独立：只配置网站应用即可启用电脑微信登录，不要求先配置公众号。没有有效服务器配置时不生成占位二维码、不模拟登录。

## 网站应用登录快速配置

在部署本项目Node后端的服务器上，把 `.env.example` 复制成 `.env` 并填写：

```dotenv
SITE_ORIGIN=https://你的域名
WECHAT_WEB_APP_ID=已审核网站应用的AppID
WECHAT_WEB_APP_SECRET=对应AppSecret
```

`SITE_ORIGIN` 只填HTTPS站点源，不带末尾斜杠或路径。微信开放平台的网站应用须已开通微信登录，授权回调域名与该域名一致，回调实际路径为 `/api/auth/wechat/callback`。静态Sites地址没有Node账号后端，单独给静态托管配置密钥不能启用登录。需在自己的HTTPS域名上部署完整服务，或者另行把账号服务接入托管平台。

重启服务后，右上角“登录 / 注册”会打开官方微信组件：电脑端支持扫码，也启用官方 `fast_login` 能力；微信客户端版本、登录和锁定状态、浏览器权限等符合官方要求时，组件提供本机微信免扫码授权，用户确认后登录。普通业务页面不自行扫描本机进程、端口或读取微信登录凭据。

官方目前说明支持微信3.9.11 for Windows及以上版本、微信4.0.0 for Mac及以上版本。详见[微信网站应用快速登录说明](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)。项目使用官方 `https://res.wx.qq.com/connect/zh_CN/htmledition/js/wxLogin.js`，传入 `fast_login: 1`、`self_redirect: false`、`stylelite: 1`；官方iframe负责快捷授权能力探测。

首次成功授权后自动注册账号，以后复用同一微信身份。服务端尝试获取允许返回的昵称和头像；没有资料权限或资料请求失败时显示通用账号标识，不伪造微信资料。右上角账号菜单提供监控入口和退出登录。关闭弹窗清理官方组件与轮询；重新打开或刷新重新签发state；过期和取消授权回到登录界面。登录不会自动开启价格通知。

建议配置后用真实账号验证：手机扫码确认、兼容电脑微信免扫码确认、切换账号、取消授权、授权过期、首次注册与重复登录、头像昵称、刷新保持会话和退出。当前自动化只验证接口/组件适配及安全状态，不代替真实微信授权测试。

## 新低口径

- 按同款谪星与已解锁孔数分组；无星格外观按0孔记录。
- 只把商品详情明确处于抽签期且有有效截止时间的数据纳入抽签历史。列表标记本身不够。
- 史低指本站开始记录后的已观察最低挂牌价，非藏宝阁全历史、非成交价。首次观察只建基线，持平不提醒。
- 当前最低价仅取最新一轮已确认且未截止的样本；历史低价可来自已经结束的抽签。
- 图鉴每轮来自藏宝阁官方游戏配置，目前29种谪星；每种采价格升序前1页，并采收藏榜前2页。按每配置最多2个候选补查详情，单轮最多60件详情。未覆盖全市场、所有数值或全部孔数组合。
- 每30分钟采集，短于30分钟的抽签窗口可能被完全漏过。若目标是及时通知，后续可单独对关注条件设置更短的采样周期，但当前不更改用户已确认的30分钟任务。

## 微信账号与域名

1. 注册适合业务主体的微信公众平台账号。先确认能取得网页授权权限，以及适用的服务通知模板权限，再决定账号类型；个人订阅号不能当作服务号的替代方案。
2. 部署本项目Node后端和数据库到可长期运行的服务器，绑定可控制的HTTPS域名。静态Sites快照没有账号后端，不能独立承担微信回调、客户登录和消息发送。
3. 在公众号管理后台配置网页授权域名、接口IP白名单及平台要求的域名校验文件。域名和IP具体要求以该账号当前后台为准。仅填AppID不能自动完成这些配置。
4. 电脑浏览器扫码使用微信开放平台已审核的网站应用；这是另一组AppID/AppSecret。微信内打开网页则使用公众号网页授权。
5. 服务号模板消息只能用于平台允许的服务通知，不能用于营销催购。先向平台确认本业务可用的模板或订阅通知能力，不保证“低价提醒”一定能通过。用户关注公众号不等于同意本站所有价格通知，客户仍需主动订阅具体配置。

官方文档：[公众号网页开发](https://developers.weixin.qq.com/doc/offiaccount/OA_Web_Apps/Wechat_webpage_authorization.html)、[网站应用微信登录](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)、[服务号模板消息](https://developers.weixin.qq.com/doc/offiaccount/Message_Management/Template_Message_Interface.html)。实现目前适配模板消息接口；若账号只获订阅通知权限，需要另加对应适配，不能直接替换模板ID。

## 服务器配置

复制 `.env.example` 为服务器上的 `.env`，填写公开HTTPS站点的 `SITE_ORIGIN`、公众号AppID和AppSecret。不要把密钥放进前端、Git、截图或聊天。

- 微信内登录：`WECHAT_OA_APP_ID`、`WECHAT_OA_APP_SECRET`。
- 电脑扫码（可选）：`WECHAT_WEB_APP_ID`、`WECHAT_WEB_APP_SECRET`。
- 授权回调路径统一为 `/api/auth/wechat/callback`，域名须与配置一致。
- 只有平台批准通知用途和模板后才填写 `WECHAT_TEMPLATE_ID`。
- `WECHAT_TEMPLATE_FIELDS` 是实际模板字段到数据含义的JSON映射。含义仅支持 `skin`、`price`、`previous`、`time`、`holes`。字段名必须来自实际批准模板，不可照抄任意示例。
- 最后显式设置 `WECHAT_SEND_ENABLED=true` 才启用发送。

修改配置后重启Node服务和采集进程。微信授权使用HTTPS Secure、HttpOnly、SameSite=Lax会话Cookie以及一次性、10分钟有效的state；本机HTTP地址不支持真正微信回调。订阅API需登录和同源Origin。配置文件只在服务端加载。

电脑登录得到的网站应用OpenID不能直接作为公众号接收者。只有来自公众号授权的身份才能用于公众号发送；两个应用在同一开放平台下返回一致UnionID时才能识别为同一用户，未取得一致UnionID时不会盲目合并身份，需要用户在微信内使用公众号授权登录。

## 提醒流程与数据

客户微信登录 → 点击某配置“订阅新低” → 后续采集出现严格新低 → 为订阅发生之后的事件入队 → 发送前再次查询商品详情 → 核实价格、状态和抽签截止 → 检查关注状态 → 发送适用的公众号服务通知。

每客户24小时最多3条，同配置6小时最多1条。重复采集不重复入队，首次建基线、持平、过期商品不发送；退订后待发消息会失效。微信HTTP受理仅记录为accepted，不宣称已送达，当前尚未实现送达事件回调。结果不确定的发送不自动重试，以避免重复骚扰；生产环境应为failed和sending状态增加管理员排查界面。

用户、会话、订阅和通知队列在 `data/accounts.sqlite`，行情在 `data/market.sqlite`，均不随静态站点发布。线上静态快照只含公开行情。此次没有向任何客户实际发送消息，真实微信授权和通知需配置后用测试账号验证。
